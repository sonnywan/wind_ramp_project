# 风电功率爬坡事件预测与预警系统 · 使用说明书

> 版本 v1.0　｜　面向：演示者 / 使用者 / 评审　｜　配套：`软件设计文档.md`

---

## 1. 系统简介

本系统预测未来 2 小时是否发生风电功率爬坡事件，并给出**方向、等级、概率与提前量**的预警，支持离线回测与实时演示。打开方式有三种：

1. **离线仪表盘**（最简单，无需服务）：双击 `output/dashboard_offline.html`。
2. **Web 仪表盘**（实时查询）：先启动后端，再用浏览器打开 `code/frontend/index.html`。
3. **Streamlit 界面**（交互式回放）：运行 `streamlit run code/app.py`。

---

## 2. 快速开始（离线仪表盘）

1. 双击 `output/dashboard_offline.html`，用 Chrome/Edge 打开。
2. 页面显示：顶部 5 个指标卡（告警总数、命中、命中率、概率源、阈值 τ）；中间功率时序图（含爬坡事件区间着色与上行概率虚线）；概率曲线图（p_up/p_dn）；底部历史告警表。
3. 图表可用底部滑块缩放、拖拽平移；鼠标悬停查看数值。

> 若图表空白，请确认 `output/echarts.min.js` 与 `dashboard_offline.html` 在同一目录（`build_frontend_snapshot.py` 会自动复制）。

## 3. 启动后端 + Web 仪表盘

### 3.1 启动后端

```powershell
python code/api_server.py --port 8000
```

看到 `serving on http://0.0.0.0:8000` 即成功。可用浏览器访问 `http://127.0.0.1:8000/health` 自检。

### 3.2 打开仪表盘

浏览器打开 `code/frontend/index.html`，右上角 API 地址默认 `http://127.0.0.1:8000`，点击"加载"。

## 4. Streamlit 交互界面

```powershell
streamlit run code/app.py
```

界面提供：
- 左侧栏：概率源切换（分类/回归）、迟滞开关、阈值 τ 滑块。
- 主区：场站功率时序、真实事件区间、上下行概率、阈值线、告警标记、事件级指标卡；可展开代价曲线与可靠性图。
- "实时模拟器"页：逐点滚动回放"实时来数→算概率→触发告警"。

## 5. 调用接口示例

### 5.1 在线预测 `/predict`

```powershell
$body = '{"window": [[0,0,1,0,10,10,0,1,0,0,0,120,90,0], ' + ('[... 重复 72 行 ...]') + ']}'
Invoke-RestMethod -Uri 'http://127.0.0.1:8000/predict' -Method Post -Body $body -ContentType 'application/json'
```

返回 `p_hat / delta_p_hat / p_up / p_dn / theta_mw`。

### 5.2 查询历史告警 `/alarms`

```powershell
Invoke-RestMethod 'http://127.0.0.1:8000/alarms?direction=up&is_hit=1&limit=20'
```

### 5.3 生成预警解释 `/alarm_explain`

```powershell
Invoke-RestMethod 'http://127.0.0.1:8000/alarm_explain?alarm_id=1'
```

返回 `summary / action / reason / source`。默认模板离线生成；配置环境变量后可调真实大模型：

```powershell
$env:LLM_BASE_URL='https://api.openai.com/v1'
$env:LLM_API_KEY='sk-...'
$env:LLM_MODEL='gpt-4o-mini'
Invoke-RestMethod 'http://127.0.0.1:8000/alarm_explain?alarm_id=1&live=true'
```

## 5.4 传感器输入闭环（输入 → 后端判断 → LED）

任务书的核心演示链路：**前端输入（手动/传感器）→ 后端查库+调模型 → 判断 → 结果返回前端，并驱动单片机 LED**。

### 5.4.1 前端操作

1. 启动后端：`python code/api_server.py --port 8000`
2. 浏览器打开 `code/frontend/index.html`，在"🔌 传感器输入"面板填写：
   - **风速 (m/s)**：传感器实测（或手动输入）
   - **功率 (MW)**：可空，留空则由经验风功率曲线自动派生
   - **风速硬阈值**：默认 12 m/s，风速达此值直接预警（对应"达阈值 LED 亮"）
   - **模型阈值 τ**：默认 0.30（两阶段模型输出的是稀有"爬坡事件概率"，量级较低，0.30 为事件级上行命中率≈54% 的操作点）
3. 点"提交判断"或"传感器模拟"（随机风速）。页面即时显示：**LED 圆点变红/灭** + 判断结果行（P̂、ΔP̂、p_up、p_dn、触发源、入库 ID）。

### 5.4.2 接口 `/predict_manual`

```powershell
$body = '{"wspd": 13.0, "wind_thr": 12.0, "led": true, "save": true}'
Invoke-RestMethod 'http://127.0.0.1:8000/predict_manual' -Method Post -Body $body -ContentType 'application/json'
```

请求字段：`wspd`(必填)、`p_mw`(可选)、`cap_mw`(可选)、`tau`(可选)、`wind_thr`(可选,默认12)、`led`(可选,默认true)、`save`(可选,默认true)。

返回示例：
```json
{
  "input": {"wspd": 13.0, "p_mw": 146.5, "wind_thr": 12.0, "tau": 0.30},
  "pred": {"P_hat": 138.3, "dP_hat": -8.3, "p_up": 0.036, "p_dn": 0.051},
  "decision": {"is_alarm": true, "direction": "up", "prob": 0.5, "level": 3, "by": "wind", "by_wind": true},
  "led": {"on": true, "real_hardware": false},
  "alarm_id": 37
}
```

### 5.4.3 判定逻辑

- **模型判定（by=model）**：模型输出 p_up/p_dn ≥ τ 触发，按概率定等级。
- **风速硬阈值（by=wind）**：风速 ≥ wind_thr 直接上爬坡预警，贴合"风速传感器达阈值即报警"。
- **LED**：任一触发即 `led.on=true`；`save=true` 且确实预警时写入 `alarm_log` 并返回 `alarm_id`。

### 5.4.4 接真实单片机 LED（串口）

无硬件时 LED 为"虚拟"（`real_hardware=false`，仅前端红灯 + 日志）。接 Arduino 时：

```powershell
$env:LED_SERIAL_PORT='COM3'
python code/api_server.py --port 8000
```

后端在判定预警时向串口发送一行指令（Arduino 按行解析）：
- `LED:ON\n` 点亮
- `LED:OFF\n` 熄灭

Arduino 端示例：读到 `LED:ON` 时 `digitalWrite(LED_PIN, HIGH)`，读到 `LED:OFF` 时 `LOW` 即可。

## 6. 常见问题

| 问题 | 处理 |
| --- | --- |
| 图表空白 | 确认 `echarts.min.js` 同目录；离线快照优先 |
| `/predict` 返回 400 | window 必须 72 步 × 14 特征，且不越界 |
| 告警表为空 | 数据库未建，运行 `python code/database.py` |
| 端口占用 | 换 `--port 8001` |
| LLM 调用失败 | 自动回退模板，查看 `fallback_reason` |
| 中文乱码（控制台） | 设置 `$env:PYTHONIOENCODING='utf-8'` |
