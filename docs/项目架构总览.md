## 1. 项目定位与学术边界

本科毕业设计「风电功率爬坡事件预测与预警系统设计与实现」（学生：王阳）。数据源 SDWPF（KDD Cup 2022），134 台 × 245 天 × 10 min，装机 201 MW。

**学术边界（方案 §0.1，全文必须守住）**：算法模型的训练、验证与全部定量性能评价一律使用 SDWPF 公开数据集；Arduino + 风速传感器硬件仅用于验证实时采集—实时推理—LED 分级预警的工程链路，**不参与模型训练与定量评估**。

三个创新点：① 爬坡事件成因归因 `ΔP = F̄·ΔC + C̄·ΔF`；② 残差经验分布概率化与校准；③ 代价敏感决策（迟滞、三级分级、双源对照）。

### 统一口径（**所有 A/B 实验不得偏离**）

| 参数 | 取值 |
| --- | --- |
| 时间分辨率 / 装机 | 10 min / 201 MW（134×1.5 MW） |
| 功率 | `P(t)=ΣPatv_i/1000` MW |
| 停机判据（唯一） | `Patv≤0 且 Wspd>2.5 m/s`；异常记录 `|Ndir|>720 或 |Wdir|>180` 打标保留 |
| 爬坡率 / 主阈值 | `R(t)=[P(t+6)−P(t)]/1h`；θ=20%×201=**40.2 MW/h**；三级 40.2/30.15/20.1 |
| 事件窗 / 提前量 / 时域 | Δt=1h(6步)，L=1h(6步)，H=2h(12步)，标签窗 `[t+6, t+12)` |
| 输入 / 展平 | 72 步 × 14 维特征；展平 24×14 + 3×14 = 378 维 |
| 切分 | train Day1–171 / val 172–208 / test 209–245，不 shuffle；归一化只用训练集 |
| 事件合并 / 迟滞 | 同向间隔 ≤6 步合并；连续 2 步 ≥τ 触发、≤0.8τ 撤销 |
| 决策目标 | `τ* = argmin (C_miss·漏警 + C_false·虚警)`，代价比 1:1 / 5:1 / 10:1 |
| 概率语义 | `P(ΔP>θ)=1−F_emp(θ−ΔP̂)`，偏置校正 `e_corr=e−2.7543 MW` |
| 测试期事件 | 主口径（≥20%）**43 条**（上 24 / 下 19），样本少、指标有波动 |

`serial_parser.py` / `serial_reader.py` / `serial_simulator.py` / `wind_ramp_arduino.ino` 均标注「备用、暂未集成」。

启动：`python code/api_server.py --port 8000`；`streamlit run code/app.py`（必须在项目根目录）；或双击 `output/dashboard_offline.html`。

## 5. 主线 C：wind_cnnlstm_pure（本次新增）

**目的**：从单机级入手解决主系统「上爬坡识别瓶颈」（主系统上行概率上限低、τ=0.6 不可达）。

**核心结论**：CNN-LSTM/LSTM/TCN 功率预测本身可达 R²≈0.90；但「先预测功率、再算爬坡增量」因回归平滑陡升而失败（预测 1h 上行增量均值仅约 31 kW vs 真实约 500 kW，召回 0.005）。改为 **LightGBM 二分类直接预测 P(上爬坡)** 后，F1 0.318 / recall 0.528 / AUC 0.787；加入 6 路气象统计特征后 AUC 0.811；完整级联（DL 隐特征 → 功率预测 → ΔP̂_up → 分类头）反而不如去掉 ΔP̂_up 的消融组（F1 0.248 vs 0.300），是重要的负结果。

**关键差异**：单机级 θ≈310 kW、36 步窗、无提前量 L、70% 时序切分、清洗无停机判据、事件级评价独立实现。详见 `../wind_cnnlstm_pure/README.md`。

**与主系统的关系**：目前完全独立，**未接入 A 的 `dataset.npz` / `run_event_eval.py` / `wind_ramp.db`，也未出现在 `thesis/` 与 `docs/` 的任何交付文档中**。若要用于改善主系统，建议「搬特征、不搬模型」：把风速变化率/湍流/功率潜势等按风场级聚合后加入 `build_dataset.FEATURE_COLS`，重训两阶段分类源并复核上行概率上限；不建议直接搬概率（口径桥接清单见子项目 README §8）。

## 8. 环境备注

- 默认 `python` 无 numpy；项目用 **`py -3.12`**（Python 3.12.10 / pandas 3.0.6 / numpy 2.5.4 / lightgbm 4.7.0 / torch 2.5.1+cu121）。
- 主系统所有脚本必须在**项目根目录**执行（`output/`、`data/` 为相对路径）；子项目必须在 `wind_cnnlstm_pure/` 根目录执行。两套环境依赖版本不一致，见子项目 README §3。
- `run_event_eval.py` 使用了 PEP 701 的 f-string 嵌套同类引号，**Python 3.12 以下为 SyntaxError**。
