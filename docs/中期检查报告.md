## 1. 课题概述

课题面向风电功率爬坡事件的预测与预警，以 SDWPF 公开风场数据集（134 台机组、201 MW、245 天、10 min）为对象，构建"数据—事件—预测—概率化—决策—系统"一体化预警系统，提出成因归因、零成本概率化、代价敏感决策三个创新点，并落地可运行、可演示的完整系统。

## 3. 阶段成果

### 3.1 核心量化结果

- **回归点预测**：测试集 MAE 11.199 MW、RMSE 16.410 MW、R² 0.8705。
- **二分类"有无爬坡"**：LightGBM AUC 0.866（对比 XGB 0.857、RF 0.828、LogReg 0.816）。
- **概率校准**：验证集 P10–P90 覆盖 0.8041（目标 0.80），Brier 0.028–0.052。
- **代价敏感**：1:1/5:1 取 τ*=0.60、10:1 取 τ*≈0.20/0.25；迟滞降归一化代价 0.186/0.093/0.256。
- **推荐操作点**（τ=0.6+迟滞）：虚警率 0.211、命中率 0.349。

### 3.2 创新点完成情况

1. **成因归因**：ΔP=F̄·ΔC+C̄·ΔF 精确分解（残差 2.84×10⁻¹⁴ MW），三分类事件，划清责任边界。
2. **零成本概率化**：残差经验分布 → 区间/超阈概率，无需分位数模型。
3. **代价敏感决策**：代价曲线 + 迟滞，事前优化漏警/虚警。

### 3.3 系统与补充实验

- 数据库（SQLite 5 表）+ REST 后端（含 `/predict`、`/alarms`、`/alarm_explain`）+ 前端 ECharts 仪表盘 + 离线快照。
- 补充实验：不同提前时间 L 敏感性、DL 特征级联组合模型、传统 ML 基线对照、大模型预警解释模块。
- 测试：`test_db_api.py` 34 例全通过。

## 4. 存在的问题

1. **概念漂移**：测试期上爬坡由 338 衰减至 99，主口径事件仅 43 条，指标存在波动；尚未做在线自适应。
2. **校准锐度**：测试集区间覆盖偏宽（0.9009），上爬坡中高概率段低估，后续可 isotonic 校准。
3. **实时流**：当前实时模式以回放/模拟演示，未接入真实 NWP。
4. **硬件局限**：Arduino 子系统单点传感器、样本有限，仅验证工程链路。
