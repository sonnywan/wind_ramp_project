# 第二章 理论基础与统一口径

本章界定爬坡事件的概念与量化定义，给出全文唯一、不可偏离的统一口径表，并对几处关键技术判断（停机判据唯一化、成因分解公式）作出澄清，为后续数据实验与系统实现奠定一致的基础。

## 2.1 爬坡事件的定义

风电功率爬坡事件一般由三个要素刻画：**幅度、持续时间、时间窗**。设风场总有功功率为 P(t)，采样间隔为 10 min。定义爬坡率 R(t) 为给定时间窗 Δt 内的功率变化率：

```
R(t) = [P(t+Δt) − P(t)] / Δt          (2-1)
```

当 |ΔP| = |P(t+Δt) − P(t)| 超过阈值 θ 时，判定在时间窗 Δt 内发生一次爬坡事件。Δt 取 1 h（6 步），θ 取装机容量的 20%（40.2 MW）。上爬坡（ΔP > θ）与下爬坡（ΔP < −θ）分别建标签、分别评价，不合并为单一任务——这是本文口径的基本约定。

## 2.2 统一口径表（全文唯一基准）

为保证训练、评价、决策与系统演示各环节口径完全一致，本文冻结如下统一口径。后续所有实验不得偏离此表。

| 参数 | 取值 | 说明 |
| --- | --- | --- |
| 时间分辨率 | 10 min | 原样保留，不重采样 |
| 功率序列 | P(t) = Σ Patv_i(t)/1000（MW） | 风场级聚合 |
| 负值处理 | Patv < 0 → 0 | 官方规则 |
| 停机判据（唯一） | Patv ≤ 0 且 Wspd > 2.5 m/s | 全文唯一判据，见 2.3 |
| 异常记录 | \|Ndir\| > 720 或 \|Wdir\| > 180 | 官方规则 |
| 爬坡率 | R(t) = [P(t+Δt) − P(t)] / Δt，Δt = 1 h = 6 步 | 式 (2-1) |
| 主阈值 θ | 20% × 201 MW = 40.2 MW/h | 敏感性取 10%/15% |
| 事件窗 Δt | 1 h |  |
| 预警提前量 L | 1 h | 事件起点前 ≥ 1 h 发出告警 |
| 预测时长 H | 2 h = 12 步 | 满足 H ≥ Δt + L |
| 方向 | 上爬坡 / 下爬坡分别建标签、分别评价 | 不合并 |
| 事件合并 | 同向且触发点间隔 ≤ Δt 合并为一次事件，起点 = 首次触发点 | 避免一次长爬坡刷多条告警 |
| 告警等级 | 一级 ≥20%、二级 ≥15%、三级 ≥10%（相对 201 MW / 1h） | 对应立即调度/准备备用/关注 |
| 迟滞 | 连续 2 步超阈发令；回落至 0.8θ 撤令 | 压虚警主要手段 |
| 数据划分 | 训练 Day 1–171 / 验证 172–208 / 测试 209–245 | 严格按时间，禁止 shuffle |
| 主指标 | 事件级：命中率、漏警率、虚警率、平均提前量 |  |
| 辅指标 | MAE / RMSE / R² | 点预测精度 |
| 概率指标 | Brier、可靠性图、代价曲线 | 支撑创新点 2、3 |

**关于预测时长与提前量的关系**：要求 H ≥ Δt + L。理由在于，预警的目标是在事件起点前至少 L 时间发出告警，而事件本身持续 Δt，预测需覆盖到事件窗口结束，故预测时长 H 至少为 Δt + L。本文取 Δt = 1 h、L = 1 h，H = 2 h，恰好满足且留有余量。

**关于分级**：一级、二级、三级分别对应幅度 ≥20%、≥15%、≥10%，与“立即调度 / 准备备用 / 关注”三类调度动作对应，避免一级预警“天天有”而失去区分度。

## 2.3 三处必须澄清的技术判断

### 2.3.1 限电不是主要污染源

在 10%/15%/20% 三档口径下统计全部触发点的成因，**气象主导占比 92–96%，工况主导仅 4–8%**。原因在于：限电/停机是持续性状态（常维持数小时），其“启停瞬间”只贡献少量爬坡事件；而长期有约 30 台机组不发电属于水平问题而非“跳变问题”。因此，成因归因在本科体量下是“必要的卫生措施 + 一个轻量亮点”，而非救火；论文主线仍应放在模型与决策层。

### 2.3.2 停机判据的唯一化

官方数据集用 Pab > 89° 判定机组静止。但本场为低风速场（容量系数约 23%），低于切入风速时机组本就顺桨待机，若单用该规则会把正常待机全部判为“未知”（实测高达 22.85%），而“Patv ≤ 0 且 Wspd > 2.5 m/s” 仅占 4.5%，后者才是真实的停机/限电状态。进一步地，在小风阈值 Wspd > 2.5 的约束下，Pab > 89° 时机组必然无法出力、功率必 ≤ 0，故该条与主判据实际等价，属冗余项。

因此，**全文采用唯一判据：Patv ≤ 0 且 Wspd > 2.5 m/s**；Pab > 89° 仅作交叉校验，不单独使用。在论文中把这一等价性交代清楚，是体现严谨性的重要细节。

### 2.3.3 成因分解的精确公式（创新点 1 的方法基础）

设 C(t) 为可用装机容量（由停机判据反推，单位 MW），F(t) = P(t)/C(t) 为容量系数。则在任意时间窗内，功率变化可精确分解为：

```
ΔP = F̄·ΔC + C̄·ΔF              (2-2)
        （工况项）  （气象项）
```

其中 F̄ = (F₁+F₂)/2，C̄ = (C₁+C₂)/2。该分解对任意 Δt 精确成立（本文实测最大残差 2.84×10⁻¹⁴ MW），无需训练、约 20 行代码即可实现，可直接支撑“工况型 / 气象型 / 混合型”事件的三分类：

- 若 |F̄·ΔC| 占主导 → **工况型**（可用容量变化驱动，主要由限电/停机引起）；
- 若 |C̄·ΔF| 占主导 → **气象型**（风速变化驱动）；
- 两者相当 → **混合型**。

这是第三章最核心的方法，也是识别工况型事件、为预警系统设定“责任边界”的依据。

## 2.4 时序预测与概率预测的理论基础

### 2.4.1 梯度提升树

梯度提升树（Gradient Boosting Decision Tree, GBDT）通过串行训练一系列弱学习器（决策树），每一棵树拟合前一轮残差的负梯度，逐步逼近目标函数。LightGBM 在 GBDT 基础上引入直方图算法、叶子生长策略（Leaf-wise）与特征/样本采样，兼顾精度与训练效率，适合中低维表格化时序特征，是本文的基线也是主模型。

### 2.4.2 深度时序模型

LSTM（长短期记忆网络）通过输入门、遗忘门、输出门缓解长序列梯度消失；TCN（时间卷积网络）通过因果空洞卷积扩大感受野并支持并行计算。二者常作为时序点预测的对比模型。本文以 LightGBM 为主模型，LSTM/TCN 作对比，用以说明“在该数据规模下，树的集成模型更能抓住事件级特征”。

### 2.4.3 残差经验分布与概率化

设回归模型给出点预测 P̂(t+H)，验证集真实残差 e = P_obs − P̂。以 e 的经验分布 F_emp 近似未来误差分布，则未来功率的区间可由 P̂(t+H) + e 的分位数给出（如 P10/P50/P90）；超阈概率为：

```
P(ΔP > θ)  = 1 − F_emp(θ − ΔP̂)          (2-3)
P(ΔP < −θ) = F_emp(−θ − ΔP̂)            (2-4)
```

其中 ΔP̂ = P̂(t+H) − P(t)。该方法**不引入额外训练成本**，仅复用点预测模型与验证集残差，即可把“是/否”升级为“以多大概率”。

### 2.4.4 概率校准与代价敏感

概率预测需检验校准质量。可靠性图将预测概率分箱，比较每箱的平均预测概率与经验频率，理想情况应贴近对角线；Brier 分数 B = (1/N)Σ(p_i − y_i)² 综合衡量准确性与锐度。

在代价敏感决策中，告警阈值的标定目标为：

```
τ* = argmin_τ E[cost] = C_miss·漏警数 + C_false·虚警数      (2-5)
```

其中 C_miss、C_false 分别为漏警与虚警代价，通常 C_miss ≫ C_false。通过扫描 τ 绘制代价曲线，可得到不同代价比下的最优阈值，实现“漏警虚警”的事前优化而非事后解释。

## 2.5 本章小结

本章给出了爬坡事件的量化定义与全文唯一的口径表，澄清了限电占比、停机判据唯一化与成因分解公式三处关键技术判断，并梳理了梯度提升树、深度时序模型、残差概率化与代价敏感决策的理论基础。这些内容构成第三章（数据与事件）与第四章（预测与决策）的公共前提。
