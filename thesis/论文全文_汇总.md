# 第一章 绪论

## 1.1 研究背景与意义

风电是当前技术最成熟、最具规模化开发条件的可再生能源之一。截至近年，我国风电并网装机容量持续居世界首位，“三北”地区大型风电基地与蒙西电网的高比例新能源接入，使风电的消纳与调度压力日益凸显。风电出力由风速驱动，具有显著的随机性、波动性与间歇性，其功率在短时间内的大幅变化——即**爬坡事件（ramp event）**——是威胁电网安全稳定运行的关键因素之一。

爬坡事件通常定义为功率在给定时间窗内相对装机容量的变化幅度超过设定阈值的事件。一次大幅上爬坡若未被提前预判，会造成调峰容量不足、频率跌落乃至切负荷；一次大幅下爬坡则可能导致弃风或常规机组深度调峰不及时。对风电场与调度部门而言，真正有价值的不只是“当前功率是多少”，而是“未来 1–2 小时内是否会发生大幅爬坡、幅度多大、方向如何、以多大概率发生”。因此，构建一个能够**提前预警爬坡事件**、并给出**可解释、可决策**信息的系统，具有明确的工程意义。

## 1.2 国内外研究现状

### 1.2.1 风电功率预测

风电功率预测按时间尺度可分为超短期（数分钟至数小时）、短期（1–3 天）与中长期。爬坡预警属于超短期/短期范畴，核心难点在于功率的剧烈非线性变化难以被平滑的点预测捕捉。按建模方法可分为物理方法、统计方法与机器学习方法：物理方法基于数值天气预报（NWP）与风功率曲线；统计方法如 ARIMA 等时间序列模型；机器学习方法如支持向量回归、梯度提升树（LightGBM/XGBoost）与深度神经网络（LSTM、TCN、Transformer 等）。近年深度时序模型在点预测精度上取得进展，但其对数据量、超参调节要求高，且在事件级（而非点级）指标上的优势并不必然成立。

### 1.2.2 爬坡事件的定义与评价

爬坡事件的检测普遍采用“幅度 + 时间窗”的阈值法：在给定时间窗 Δt 内，若功率变化量 ΔP 超过阈值 θ（常以装机容量百分比表示），则判定发生爬坡。Bossavy、Kariniotakis 等系统研究了爬坡事件的定义体系与评价方法，指出事件级指标（命中率、漏警率、虚警率、提前量）比点误差更能反映预警系统的实际价值。事件合并规则（将时间上相邻的同向触发点合并为一次事件）是避免“一次长爬坡刷出多条告警”的关键工程处理。

### 1.2.3 概率预测与校准

相比于确定性点预测，概率预测给出未来功率的分布或超阈概率，能直接支撑风险决策。概率预测的主流方法包括分位数回归、集合预报与基于残差分布的区间构造。无论采用何种方法，**校准（calibration）**都是评价概率预测质量的核心：可靠性图（reliability diagram）衡量预测概率与经验频率的一致性，Brier 分数综合刻画概率预测的准确性与锐度。

### 1.2.4 代价敏感的预警决策

在预警场景中，漏警（miss）与虚警（false alarm）的代价往往高度不对称：漏掉一次大幅爬坡的代价远高于一次虚警。因此，告警阈值不应固定取 0.5，而应按代价敏感原则标定：τ* = argmin_τ E[cost] = C_miss·漏警数 + C_false·虚警数。代价曲线与迟滞（hysteresis）机制是降低虚警、提升决策质量的主要手段。

## 1.3 现有研究的不足

综合上述现状，面向工程落地的爬坡预警仍存在以下不足：

1. **重“点预测精度”、轻“事件级评价”**。大量研究以 MAE/RMSE/R² 为唯一指标，但点误差小并不意味着能抓到爬坡事件；缺少命中率、漏警率、虚警率、提前量等事件级指标的横向对比。
2. **预警输出停留在“是/否”，缺少概率语义**。确定性二分类告警无法表达“以多大概率发生”，难以对接后续调度决策与风险分级。
3. **告警阈值靠经验设定，缺少代价敏感标定**。固定阈值忽略了漏警与虚警的代价不对称，也缺少对迟滞等工程抑制手段的定量评估。
4. **对“不可避免的漏警”缺乏归因**。部分爬坡由限电、停机等工况因素引起，属于模型难以从气象特征预测的部分；若不加区分地统计，会误导对模型能力的评价。
5. **系统实现与算法脱节**。不少研究止步于离线实验，缺少可运行、可演示、可复现的完整预警系统。

## 1.4 本文研究内容与创新点

针对上述不足，本文以 SDWPF 公开风场数据集为对象，构建“预测—概率化—决策—系统”一体化的风电功率爬坡预警系统。主要研究内容与创新点如下：

**创新点 1：爬坡事件成因归因，为预警能力划清责任边界。** 基于 ΔP = F̄·ΔC + C̄·ΔF 的精确分解，将每个爬坡事件分解为“工况项”与“气象项”，据此分类为工况型、气象型与混合型。预警指标主要在气象型事件上统计，工况型事件单独列出并对系统降级处理，从而解释掉一部分不可避免的漏警，避免模型“背锅”、指标失真。

**创新点 2：零额外训练成本的概率化预警。** 不引入分位数模型，而是复用回归模型在验证集上的残差经验分布：由点预测 P̂(t+H) 与残差分布，直接构造未来功率的 P10/P50/P90 区间，并以 P(ΔP>θ) = 1−F_emp(θ−ΔP̂) 计算超阈概率。通过可靠性图与 Brier 分数检验校准质量，把预警从“是/否”升级为“以多大概率”。

**创新点 3：代价敏感告警决策。** 以 τ* = argmin_τ (C_miss·漏警数 + C_false·虚警数) 标定告警阈值，在验证集上扫描并绘制代价曲线；叠加事件合并与迟滞机制，对比有/无决策层的虚警率下降幅度。将“漏警虚警分析”从事后解释升级为事前可优化。

在上述算法基础上，本文进一步实现了一个**支持离线回测与实时演示双模式的预警系统**，并以 Arduino + 传感器搭建实时采集与 LED 分级预警的工程子系统，形成“采集—推理—决策—预警”的完整闭环。硬件子系统仅用于验证系统实时性与工程链路，不参与模型训练与定量评价。

## 1.5 技术路线

本文技术路线如下：

1. **数据与事件层**：数据清洗（缺失/负值/异常处理）→ 统一口径（Δt=1h、θ=20%、L=1h、H=2h）→ 爬坡事件检测与合并 → 成因分解归因 → 事件清单。
2. **预测层**：特征工程（14 维风场级特征）→ 基线模型（LightGBM）与深度学习模型（LSTM/TCN）对比 → 回归主模型冻结。
3. **概率化层**：残差经验分布 → 区间预测与超阈概率 → 可靠性图与 Brier 校准检验。
4. **决策层**：代价敏感阈值标定 → 事件合并 + 迟滞 → 三级分级与方向判定。
5. **系统层**：离线回测 + 实时演示双模式 → 可视化界面 → 实时采集与 LED 预警子系统。
6. **评价层**：事件级指标（命中率、漏警率、虚警率、提前量）+ 概率指标（Brier、可靠性）+ 代价指标（归一化代价）。

# 第二章 理论基础与统一口径

本章界定爬坡事件的概念与量化定义，给出全文唯一、不可偏离的统一口径表，并对几处关键技术判断（停机判据唯一化、成因分解公式）作出澄清，为后续数据实验与系统实现奠定一致的基础。

## 2.1 爬坡事件的定义

风电功率爬坡事件一般由三个要素刻画：**幅度、持续时间、时间窗**。设风场总有功功率为 P(t)，采样间隔为 10 min。定义爬坡率 R(t) 为给定时间窗 Δt 内的功率变化率：

```
R(t) = [P(t+Δt) − P(t)] / Δt          (2-1)
```

当 |ΔP| = |P(t+Δt) − P(t)| 超过阈值 θ 时，判定在时间窗 Δt 内发生一次爬坡事件。Δt 取 1 h（6 步），θ 取装机容量的 20%（40.2 MW）。上爬坡（ΔP > θ）与下爬坡（ΔP < −θ）分别建标签、分别评价，不合并为单一任务——这是本文口径的基本约定。

## 2.2 统一口径表（全文唯一基准）

为保证训练、评价、决策与系统演示各环节口径完全一致，本文冻结如下统一口径。后续所有实验不得偏离此表。

| 参数 | 取值 | 说明 |
| --- | --- | --- |
| 时间分辨率 | 10 min | 原样保留，不重采样 |
| 功率序列 | P(t) = Σ Patv_i(t)/1000（MW） | 风场级聚合 |
| 负值处理 | Patv < 0 → 0 | 官方规则 |
| 停机判据（唯一） | Patv ≤ 0 且 Wspd > 2.5 m/s | 全文唯一判据，见 2.3 |
| 异常记录 | \|Ndir\| > 720 或 \|Wdir\| > 180 | 官方规则 |
| 爬坡率 | R(t) = [P(t+Δt) − P(t)] / Δt，Δt = 1 h = 6 步 | 式 (2-1) |
| 主阈值 θ | 20% × 201 MW = 40.2 MW/h | 敏感性取 10%/15% |
| 事件窗 Δt | 1 h |  |
| 预警提前量 L | 1 h | 事件起点前 ≥ 1 h 发出告警 |
| 预测时长 H | 2 h = 12 步 | 满足 H ≥ Δt + L |
| 方向 | 上爬坡 / 下爬坡分别建标签、分别评价 | 不合并 |
| 事件合并 | 同向且触发点间隔 ≤ Δt 合并为一次事件，起点 = 首次触发点 | 避免一次长爬坡刷多条告警 |
| 告警等级 | 一级 ≥20%、二级 ≥15%、三级 ≥10%（相对 201 MW / 1h） | 对应立即调度/准备备用/关注 |
| 迟滞 | 连续 2 步超阈发令；回落至 0.8θ 撤令 | 压虚警主要手段 |
| 数据划分 | 训练 Day 1–171 / 验证 172–208 / 测试 209–245 | 严格按时间，禁止 shuffle |
| 主指标 | 事件级：命中率、漏警率、虚警率、平均提前量 |  |
| 辅指标 | MAE / RMSE / R² | 点预测精度 |
| 概率指标 | Brier、可靠性图、代价曲线 | 支撑创新点 2、3 |

**关于预测时长与提前量的关系**：要求 H ≥ Δt + L。理由在于，预警的目标是在事件起点前至少 L 时间发出告警，而事件本身持续 Δt，预测需覆盖到事件窗口结束，故预测时长 H 至少为 Δt + L。本文取 Δt = 1 h、L = 1 h，H = 2 h，恰好满足且留有余量。

**关于分级**：一级、二级、三级分别对应幅度 ≥20%、≥15%、≥10%，与“立即调度 / 准备备用 / 关注”三类调度动作对应，避免一级预警“天天有”而失去区分度。

## 2.3 三处必须澄清的技术判断

### 2.3.1 限电不是主要污染源

在 10%/15%/20% 三档口径下统计全部触发点的成因，**气象主导占比 92–96%，工况主导仅 4–8%**。原因在于：限电/停机是持续性状态（常维持数小时），其“启停瞬间”只贡献少量爬坡事件；而长期有约 30 台机组不发电属于水平问题而非“跳变问题”。因此，成因归因在本科体量下是“必要的卫生措施 + 一个轻量亮点”，而非救火；论文主线仍应放在模型与决策层。

### 2.3.2 停机判据的唯一化

官方数据集用 Pab > 89° 判定机组静止。但本场为低风速场（容量系数约 23%），低于切入风速时机组本就顺桨待机，若单用该规则会把正常待机全部判为“未知”（实测高达 22.85%），而“Patv ≤ 0 且 Wspd > 2.5 m/s” 仅占 4.5%，后者才是真实的停机/限电状态。进一步地，在小风阈值 Wspd > 2.5 的约束下，Pab > 89° 时机组必然无法出力、功率必 ≤ 0，故该条与主判据实际等价，属冗余项。

因此，**全文采用唯一判据：Patv ≤ 0 且 Wspd > 2.5 m/s**；Pab > 89° 仅作交叉校验，不单独使用。在论文中把这一等价性交代清楚，是体现严谨性的重要细节。

### 2.3.3 成因分解的精确公式（创新点 1 的方法基础）

设 C(t) 为可用装机容量（由停机判据反推，单位 MW），F(t) = P(t)/C(t) 为容量系数。则在任意时间窗内，功率变化可精确分解为：

```
ΔP = F̄·ΔC + C̄·ΔF              (2-2)
        （工况项）  （气象项）
```

其中 F̄ = (F₁+F₂)/2，C̄ = (C₁+C₂)/2。该分解对任意 Δt 精确成立（本文实测最大残差 2.84×10⁻¹⁴ MW），无需训练、约 20 行代码即可实现，可直接支撑“工况型 / 气象型 / 混合型”事件的三分类：

- 若 |F̄·ΔC| 占主导 → **工况型**（可用容量变化驱动，主要由限电/停机引起）；
- 若 |C̄·ΔF| 占主导 → **气象型**（风速变化驱动）；
- 两者相当 → **混合型**。

这是第三章最核心的方法，也是识别工况型事件、为预警系统设定“责任边界”的依据。

## 2.4 时序预测与概率预测的理论基础

### 2.4.1 梯度提升树

梯度提升树（Gradient Boosting Decision Tree, GBDT）通过串行训练一系列弱学习器（决策树），每一棵树拟合前一轮残差的负梯度，逐步逼近目标函数。LightGBM 在 GBDT 基础上引入直方图算法、叶子生长策略（Leaf-wise）与特征/样本采样，兼顾精度与训练效率，适合中低维表格化时序特征，是本文的基线也是主模型。

### 2.4.2 深度时序模型

LSTM（长短期记忆网络）通过输入门、遗忘门、输出门缓解长序列梯度消失；TCN（时间卷积网络）通过因果空洞卷积扩大感受野并支持并行计算。二者常作为时序点预测的对比模型。本文以 LightGBM 为主模型，LSTM/TCN 作对比，用以说明“在该数据规模下，树的集成模型更能抓住事件级特征”。

### 2.4.3 残差经验分布与概率化

设回归模型给出点预测 P̂(t+H)，验证集真实残差 e = P_obs − P̂。以 e 的经验分布 F_emp 近似未来误差分布，则未来功率的区间可由 P̂(t+H) + e 的分位数给出（如 P10/P50/P90）；超阈概率为：

```
P(ΔP > θ)  = 1 − F_emp(θ − ΔP̂)          (2-3)
P(ΔP < −θ) = F_emp(−θ − ΔP̂)            (2-4)
```

其中 ΔP̂ = P̂(t+H) − P(t)。该方法**不引入额外训练成本**，仅复用点预测模型与验证集残差，即可把“是/否”升级为“以多大概率”。

### 2.4.4 概率校准与代价敏感

概率预测需检验校准质量。可靠性图将预测概率分箱，比较每箱的平均预测概率与经验频率，理想情况应贴近对角线；Brier 分数 B = (1/N)Σ(p_i − y_i)² 综合衡量准确性与锐度。

在代价敏感决策中，告警阈值的标定目标为：

```
τ* = argmin_τ E[cost] = C_miss·漏警数 + C_false·虚警数      (2-5)
```

其中 C_miss、C_false 分别为漏警与虚警代价，通常 C_miss ≫ C_false。通过扫描 τ 绘制代价曲线，可得到不同代价比下的最优阈值，实现“漏警虚警”的事前优化而非事后解释。

## 2.5 本章小结

本章给出了爬坡事件的量化定义与全文唯一的口径表，澄清了限电占比、停机判据唯一化与成因分解公式三处关键技术判断，并梳理了梯度提升树、深度时序模型、残差概率化与代价敏感决策的理论基础。这些内容构成第三章（数据与事件）与第四章（预测与决策）的公共前提。

# 第三章 数据与事件

本章介绍数据来源、清洗处理、爬坡事件检测与成因归因，回答“数据是什么样、有多少爬坡事件、这些事件由什么引起”三个问题，为第四章建模提供事件清单与责任边界。本章全部数字均为基于脚本的实测结果，可复现。

## 3.1 数据来源

本文采用 SDWPF（Spatial Dynamic Wind Power Forecasting）公开风场数据集（KDD Cup 2022），由 134 台 SL1500/82 型风电机组组成，单机容量 1.5 MW，风场总装机 201 MW，时间跨度 245 天，采样分辨率 10 min，共 4,727,520 条记录（= 134 台 × 245 天 × 144 步），数据结构完整、无丢行。

> 数据说明：该数据来自龙源某风电场（地点未披露），本文仅将其应用场景与考核规则对标蒙西/“三北”基地，不表述为数据来自蒙西。参考原始数据论文 Zhou J. et al., SDWPF: A Dataset for Spatial Dynamic Wind Power Forecasting over a Large Turbine Array, Scientific Data, 2024, 11: 649。

### 3.2.2 角度异常的条数说明

实测角度异常为 127 条（判据 |Ndir|>720 或 |Wdir|>180）。与早期方案估计的 141 条存在差异，源于开闭区间处理方式不同。本文以代码实测的 127 条为准，并在正文注明判据，不硬抄估计数字。

## 3.3 停机判据与成因分解

停机判据的唯一化已在 2.3.2 详述。据此，对每个爬坡事件用式 (2-2) 做成因分解，并将事件分类为工况型、气象型、混合型。分解残差最大 2.84×10⁻¹⁴ MW，表明该公式对任意 Δt 精确成立，因此归因结果可直接作为事件的客观属性（并非模型推测）。

### 3.4.1 成因占比与责任边界

气象型事件占 **95.97%**，工况型仅 44 条、混合型 19 条。这印证了 2.3.1 的判断：预警系统主要面对的是气象型爬坡，工况型事件属于“不可避免的漏警”的一部分。因此本文的预警指标**主要在气象型事件上统计**，工况型事件单独列表并对系统降级处理（不承诺预警）。这为模型划清了能力边界，避免把工况型漏警误算为模型缺陷、导致指标失真。

### 3.4.2 事件在测试期的稀疏性（重要数据事实）

按时间划分（Day 1–171 训练 / 172–208 验证 / 209–245 测试），起点落在测试期的主口径事件仅 **43 条**（上行 24 / 下行 19）。这是全场级事件，与机组数无关；其稀疏性来自测试期末端爬坡明显减少——上爬坡数量随 Day 推进由 Day210 段的 338 衰减至 Day230 段的 99。这一时间漂移是第四章泛化评价中不可忽视的背景，也导致测试期各阈值下的事件级指标存在正常波动。

## 3.6 本章小结

本章基于 SDWPF 实测数据完成清洗与事件检测：全量事件 1,565 条、主口径 752 条（约 3.07 次/天），其中气象型占 95.97%。成因分解公式精确成立（残差 2.84×10⁻¹⁴ MW），据此为预警划定了“主要面对气象型、对工况型降级”的责任边界。同时交代了测试期仅 43 条主口径事件这一重要数据事实。样本按时间严格划分、无 shuffle，构造 14 维特征与 72 步输入窗，为第四章建模奠定基础。

# 第四章 预测与决策

本章是全文核心，涵盖预测模型、概率化与校准（创新点 2）、代价敏感决策（创新点 3）三大部分，并给出双源对照与三级分级回传的定量结果。所有实验均基于 SDWPF 测试集，评价口径严格遵循第二章统一口径。

## 4.1 预测任务与模型框架

本文的预警链路为：以 72 步（12h）历史特征为输入，预测未来 H=12 步（2h）的功率点预测 P̂(t+H)，再由残差经验分布给出超阈概率 P(ΔP>θ)，最后由代价敏感决策层依据概率与迟滞机制发出分级告警。

根据第二章口径，预警的核心任务是“未来是否发生爬坡”（有无），方向作为附加输出分别评价。模型对比实验表明，二分类“有无爬坡”上 LightGBM 显著优于深度学习模型，故本文以 LightGBM 为主模型。

据此，本文主线定为：核心任务为**二分类爬坡预警（有无）**，方向作为附加输出；LightGBM 作主模型，TCN/LSTM 作对比。

## 4.3 回归主模型（创新点 2 基础）

为实现概率化预警，需先获得功率点预测及其残差分布。为此训练一个 LightGBM 回归模型，直接预测场站总有功 P_mw(t+12)（原始 MW 量纲，不归一化）。特征为复用归一化特征后展平（末 24 步）+ 均值/标准差/斜率，共 378 维；超参 lr=0.03、leaves=31、max_depth=6、min_child=60、feature_fraction=0.5、bagging 0.8/5、L1=0.5、L2=2.0，early stopping=80，best_iter=160。

**表 4-3 回归点预测精度**

| 集合 | n | MAE (MW) | RMSE (MW) | R² | 残差均值 | 残差std |
|---|---|---|---|---|---|---|
| train | 24,326 | 14.812 | 21.539 | 0.8356 | 0.043 | 21.539 |
| val | 5,328 | 16.193 | 22.986 | 0.8394 | **+2.754** | 22.821 |
| test | 5,316 | 11.199 | 16.410 | **0.8705** | 0.531 | 16.402 |

测试集 MAE 11.199 MW、RMSE 16.410 MW、R² 0.8705，点预测精度满足预警需求。关键观察：**验证集残差均值为 +2.754 MW**（系统性低估），这说明残差并非零均值，需在概率化时做偏置校正（见 4.4）。

## 4.4 概率化与校准（创新点 2）

### 4.4.1 方法

本文不引入分位数模型，而是复用上述回归模型的验证集残差经验分布：

1. **偏置校正**：e_corr = e − mean(e_val) = e − 2.754 MW；
2. **区间构造**：逐样本未来功率分布 = P̂(t+H) + e_corr，e_corr ~ F_emp（验证集残差经验分布），由其分位数给出 P10/P50/P90；
3. **超阈概率**：按式 (2-3)(2-4)，P(ΔP>θ) = 1 − F_emp(θ − ΔP̂)，P(ΔP<−θ) = F_emp(−θ − ΔP̂)，其中 ΔP̂ = P̂(t+H) − P(t)，经验 CDF 用 `np.searchsorted` 实现，**不采用正态近似**。θ = ±40.2 MW（≈20% 装机）。

### 4.4.3 结果分析

验证集覆盖率 0.8041 精准命中目标 0.80，说明残差经验分布在验证集上校准良好，方法有效。测试集覆盖率 0.9009 偏宽，其根源是测试段误差（MAE 11.2 / std 16.4）显著小于验证段（MAE 16.2 / std 22.8），属数据分布差异而非实现缺陷。Brier 分数在测试集上更低（上爬坡 0.0317、下爬坡 0.0281），同样反映测试段误差更小。

可靠性图显示：上爬坡在中高概率段（0.44–0.76）存在明显低估（预测 0.445 对应经验 0.607、预测 0.759 对应经验 1.000），下爬坡整体略高估。这是后续可引入 isotonic 单调校准改进的点。总体而言，创新点 2 的“零额外训练成本概率化”方法在验证集上校准良好，产出的 p_up/p_dn 可直接接入决策层。

## 4.5 代价敏感决策（创新点 3）

### 4.5.1 代价模型

本文采用代价比 C_miss : C_false，固定 C_false = 1，分别取 {1:1, 5:1, 10:1}。总代价 TotalCost = ratio × 漏警数 + 虚警数，归一化代价 = TotalCost / 真实事件数。扫描 τ ∈ [0.05, 0.95]（步长 0.05，共 19 档），无迟滞/带迟滞两组并行。真实事件取测试期主口径 43 条。

### 4.5.2 迟滞机制

迟滞的触发条件为连续 2 步概率 ≥ τ，撤销条件为告警态下概率 ≤ 0.8τ，其余保持上一状态。迟滞是压制虚警的主要工程手段，其效果在 4.5.3 与 4.5.4 中量化。

### 4.5.3 迟滞抑制虚警效果（同阈值对比）

**表 4-6 迟滞对虚警率的抑制（测试集）**

| τ | 虚警率(无) | 虚警率(带) | 命中率(无) | 命中率(带) | 预测事件(无→带) |
| --- | --- | --- | --- | --- | --- |
| 0.30 | 0.777 | 0.732 | 0.628 | 0.605 | 121→97 |
| 0.40 | 0.654 | 0.634 | 0.419 | 0.349 | 52→41 |
| 0.50 | 0.629 | **0.480** | 0.302 | 0.302 | 35→25 |
| 0.60 | 0.448 | **0.211** | 0.372 | 0.349 | 29→19 |
| 0.70 | 0.556 | 0.429 | 0.093 | 0.093 | 9→7 |

迟滞在 τ=0.5/0.6 处虚警率显著下降（0.63→0.48、0.45→0.21），命中率基本持平（仅损失约 0–7 个百分点召回）。**τ=0.6 + 迟滞为“高精度低虚警”操作点**（虚警 0.211、命中 0.349、仅 19 个告警事件）。

**两条关键结论（支撑创新点 3）**：

1. **代价比显著改变最优阈值**：1:1/5:1 时 τ*=0.60（偏向压虚警）；10:1 时因漏警代价高，最优阈值骤降至 0.20（无）/0.25（带），以牺牲大量虚警换取漏警从 27 降至 13/14。这正是代价敏感标定的核心价值。
2. **迟滞在各代价比下均降低归一化代价**：1:1 降 0.186、5:1 降 0.093、10:1 降 0.256；且带迟滞的归一化代价在所有代价比下均低于无迟滞。迟滞通过削减冗余虚警（13→4、106→85）在几乎不增漏警的前提下改善总代价。

**推荐操作点**：常规运行（1:1/5:1）取 τ=0.60 + 迟滞（代价最低、虚警 0.21）；高风险时段（漏警代价 10 倍）取 τ≈0.25 + 迟滞。

| **全局** | **129** | **18** | **111** | — | — |

全局虚警数（不分配等级）：1。

**结论**：检出率随等级递增（一级 0.209 > 二级 0.125 > 三级 0.097），符合“幅度越大越易检出”的物理直觉，支撑“分级预警的检出能力随等级单调递增”的论断。三级（关注级）检出率偏低属预期——小幅度爬坡较难捕捉，工程上三级本就定位为“关注”，靠迟滞不误报即可，不苛求高召回。全量口径整体命中率 18/129≈0.14 偏低，主因是三级事件数量多（62 条）且幅度小，须与主口径检出水平区分陈述。

## 4.7 双源对照（创新点 2 → 3 打通）

为验证创新点 2 产出的回归残差概率能否无缝接入创新点 3 的决策层，本文做了严格同源对照：两套概率源（cls：三分类概率；reg：回归残差超阈概率）共用同一套事件口径、迟滞逻辑与代价模型，仅概率来源不同。

**表 4-9 不同代价比 × 迟滞：最优 τ* 与归一化代价（双源对照）**

| 代价比 | 迟滞 | 最优τ*(分类) | 代价(分类) | 最优τ*(回归) | 代价(回归) | 差(回归−分类) |
|---|---|---|---|---|---|---|
| 1:1 | 无 | 0.60 | 0.9302 | 0.85 | 0.9302 | +0.0000 |
| 1:1 | 带 | 0.60 | 0.7442 | 0.85 | 0.9767 | +0.2326 |
| 5:1 | 无 | 0.60 | 3.4419 | 0.35 | 3.3023 | **−0.1395** |
| 5:1 | 带 | 0.60 | 3.3488 | 0.35 | 3.5814 | +0.2326 |
| 10:1 | 无 | 0.20 | 5.4884 | 0.05 | 5.0233 | **−0.4651** |
| 10:1 | 带 | 0.25 | 5.2326 | 0.05 | 5.3488 | +0.1163 |

**如实结论**：

1. **两源 τ 语义不同、不可直接横比**：分类源输出类别概率，回归源输出超阈概率 P(ΔP>θ)（θ 固定），故 τ* 落在不同量级（分类约 0.2–0.6，回归约 0.05–0.85）。可比的是同一源内最优点处的代价/命中/虚警。
2. **回归源在无迟滞 + 高代价比（5:1/10:1）更优**，10:1 优势最大（代价 −0.4651）；**带迟滞时全面略逊于分类源**。机理在于回归超阈概率时序平滑，迟滞对其虚警的额外抑制增益小；分类概率抖动大，迟滞削虚警更有效。即**迟滞收益与概率源平滑度相关**。
3. 定位为**互补**而非谁碾压谁：分类源适合搭配迟滞、追求低虚警的在线告警；回归源适合对漏警敏感、需绝对超阈概率语义的场景。

本节的方法学意义在于：创新点 2 的校准概率**可无缝接入创新点 3 的同一决策层**，并量化了概率源差异对事件级收益的影响，这是打通两点、且被数据如实检验的结论。

## 4.8 本章小结

本章以 LightGBM 为主模型、LSTM/TCN 为对比，在二分类“有无爬坡”上实现 AUC 0.866；回归主模型测试集 MAE 11.199 MW、R² 0.8705；残差经验分布概率化在验证集实现 0.8041 区间覆盖（目标 0.80）；代价敏感决策表明代价比显著改变最优阈值（1:1/5:1 取 0.60，10:1 取 0.20/0.25），迟滞在各代价比下均降低归一化代价（0.186/0.093/0.256）；三级分级检出率随等级递增；双源对照验证了创新点 2→3 的可打通性与互补性。以上结果构成完整“预测—概率化—决策”链条，为第五章系统实现提供算法内核。

# 第五章 系统实现

本章将第三、四章的算法内核落地为可运行、可演示的预警系统，介绍总体架构、数据管理、预测推理与决策层、实时采集与 LED 预警子系统、可视化界面与系统测试。系统支持离线回测与实时演示双模式，并遵循“决策层只认步数、不认分钟”的统一时间基原则，保证两种模式共用同一套决策逻辑。

## 5.1 总体架构

系统采用分层解耦架构，自下而上分为数据层、算法层、决策层、交互层与硬件层：

```
┌─────────────────────────────────────────────┐
│  交互层  Streamlit 可视化（离线回放 / 实时模拟）      │
├─────────────────────────────────────────────┤
│  决策层  τ 标定 + 事件合并 + 迟滞 + 三级分级 + 方向     │
├─────────────────────────────────────────────┤
│  算法层  特征工程 → LightGBM 回归/分类 → 残差概率化    │
├─────────────────────────────────────────────┤
│  数据层  清洗 → 统一口径 → 事件检测 → 归因 → 滑窗数据集 │
├─────────────────────────────────────────────┤
│  硬件层  Arduino 采集 → 串口解析 → 滚动窗口（演示）    │
└─────────────────────────────────────────────┘
```

各层通过统一的数据契约（步序列 `t_idx` + 双通道概率 `p_up/p_dn`）衔接，算法与决策与数据源解耦，因此离线数据（CSV）与实时数据（串口）只需提供同样的“步序列”，其后全部调用同一套决策层模块。

## 5.2 数据管理

数据层由 `data_clean.py` 与 `build_dataset.py` 两个脚本构成，负责：

- **清洗**：按统一口径完成缺失插值（机组+按天分段）、负值置 0、停机判据、角度异常打标，输出机组级 parquet 与场站级 CSV。
- **事件检测与归因**：由爬坡率与阈值检测事件并合并，用 ΔP = F̄·ΔC + C̄·ΔF 分解归因，输出事件清单 `ramp_events.csv` 与逐点标签 `ramp_labels.csv`。
- **数据集构建**：构造 14 维风场级特征，按时间切分（训练/验证/测试），滑窗采样（N=72），统计量仅用训练集计算，输出 `dataset.npz`（含 feat_mu/feat_sd/feature_cols）。

以上产物为算法层与决策层提供统一的输入，保证实验可复现。

## 5.3 预测推理与决策层

### 5.3.1 在线推理底座

为支持实时场景，训练完成的 LightGBM 回归模型经 joblib 打包导出为 `reg_lightgbm_model.pkl`，内含 booster、最优迭代轮次、`keep_last`、预测步长 H、特征列名、验证集残差排序数组、残差偏置与默认阈值 θ 等全部推理所需信息。

配套的推理模块 `reg_infer.py` 提供：

- `flatten_with_stats`：与训练完全一致的特征展平；
- `predict_power`：对新窗口输出 P̂(t+H)；
- `prob_exceed`：基于验证集残差经验分布（含偏置校正）计算 P(ΔP>θ)/P(ΔP<−θ)；
- `infer`：一站式输出 P̂、ΔP̂、p_up、p_dn。

一致性验证表明：加载模型对测试集样本的推理结果与训练时预测点完全一致（最大偏差 7×10⁻⁶ MW），复算概率与离线产物 `reg_prob.npz` 一致（最大偏差约 3×10⁻⁸），确保了在线推理与离线实验同口径。

### 5.3.2 决策层

决策层以双通道概率为输入，依次执行：阈值判定 → 事件合并 → 迟滞 → 三级分级与方向回传。其参数（连续 2 步触发、回落 0.8τ 撤销、合并间隔 Δt 步）全部以“步数”表达，与时间基无关，故离线与演示口径完全等价。决策层的输出为逐时刻告警状态与等级/方向，供可视化与硬件回传使用。

## 5.4 实时采集与 LED 预警子系统

> 学术边界重申：本节子系统仅用于验证系统实时采集、实时推理与分级预警的工程功能，其采集样本不参与模型训练与定量性能评估；全部定量指标以离线 SDWPF 回测为准。

### 5.4.1 子系统组成

实时子系统由 Arduino 采集端、PC 串口解析端与 LED 指示端构成，形成“采集—推理—决策—预警”闭环：

```
风速传感器 → Arduino（读取/换算/组帧/校验）→ USB 串口 →
PC（解析 → 滚动窗口 → 模型推理 → 决策层）→ 串口回传 →
Arduino（解析等级与方向）→ RGB LED 分级预警
```

### 5.4.2 串口通信协议

为保证数据可靠，定义带校验的文本帧协议：

- **上报帧（Arduino → PC）**：`$W,<风速>,<风向>,<环温>,<舱温>,<机舱方向>,<叶片角1>,<叶片角2>,<叶片角3>,<变桨角>,<可用容量>,<当前功率>*<chk>\r\n`，`chk` 为对 `$` 与 `*` 之间字符逐字节异或校验。
- **下发帧（PC → Arduino）**：携带预警等级（0–3）与方向（U/D/N），Arduino 解析后驱动 RGB LED。

PC 端解析器 `serial_parser.py` 负责：帧同步（定位 `$W` 与行尾）、异或校验、数值解析、派生特征（风向/机舱方向 sin/cos、容量系数 R），并维护 72 步滚动窗口、以训练集统计量归一化。校验失败帧被丢弃，避免脏数据进入推理。

### 5.4.3 数据模拟与链路验证

在硬件尚未到货前，提供 `serial_simulator.py`：以 SDWPF 真实特征按协议拼帧，模拟串口数据流。端到端验证结果：生成 100 帧 → 解析 100/100 成功 → 滚动窗口填满 → 推理输出 P̂/ΔP̂/p_up/p_dn，链路全部通过。这保证了硬件到货后只需将数据源从模拟器切换为真实串口（`serial_reader.py --port COMx`），系统逻辑无需改动。

### 5.4.4 LED 分级预警映射

LED 以颜色表方向、以闪烁频率表等级：红色表示上爬坡、蓝色表示下爬坡、绿色表示无预警；常亮对应一级（立即调度）、1 Hz 闪烁对应二级（准备备用）、0.5 Hz 闪烁对应三级（关注）、灭灯表示无告警。该映射与第四章的三级分级口径一致，使预警结果可被现场直观识别。

## 5.5 可视化界面

系统以 Streamlit 实现可视化界面（`app.py`），支持双模式：

- **离线回放**：读取现成的 npz/csv 结果，展示场站功率时序、真实爬坡事件区间、上/下行概率曲线、阈值线与告警标记、事件级指标卡，并可展开查看代价曲线与可靠性图。
- **实时模拟器**：以测试段真实模型输出的 p_up/p_dn 逐点滚动回放，模拟“实时来数→算概率→触发告警”的过程，含进度条、当前功率/概率与告警状态实时显示。

界面侧栏支持切换概率源（分类/回归校准，对应创新点 2）、迟滞开关与阈值 τ 滑块，且事件定义与迟滞规则同后端完全一致。该界面零重算直接读取结果，保证演示流畅。

# 第六章 总结与展望

## 6.1 全文总结

本文以 SDWPF 公开风场数据集为对象，围绕“风电功率爬坡事件预测与预警”这一工程问题，构建了“数据—事件—预测—概率化—决策—系统”一体化预警系统，完成的主要工作如下：

**1. 数据与事件基础。** 严格按统一口径（Δt=1h、θ=20%、L=1h、H=2h）完成数据清洗（Wspd/Patv 同步缺失 1.047%、负值 26.72% 置 0、停机判据唯一化），检测到主口径（≥20%）爬坡事件 752 条（约 3.07 次/天），上/下爬坡分别 783/782 条，为建模提供了充分的事件样本与明确的评价口径。

**2. 成因归因（创新点 1）。** 基于 ΔP = F̄·ΔC + C̄·ΔF 的精确分解（残差 2.84×10⁻¹⁴ MW），将事件分类为工况型/气象型/混合型，实测气象型占 95.97%。据此把预警指标主要建立在气象型事件上，对工况型事件降级处理，为模型划清了能力边界，避免“不可避免的漏警”误伤指标。

**3. 建模与对比。** 以 14 维风场级特征、72 步输入窗、严格按时间划分，对比 LightGBM 与 LSTM/TCN。二分类“有无爬坡”上 LightGBM 最优（AUC 0.866），回归主模型测试集 MAE 11.199 MW、R² 0.8705。“LightGBM 在该数据上更优”本身构成有效结论。

**4. 概率化预警（创新点 2）。** 以零额外训练成本的残差经验分布方法构造 P10/P50/P90 区间与超阈概率 P(ΔP>θ)，验证集区间覆盖 0.8041（目标 0.80），Brier 0.028–0.052，把预警从“是/否”升级为“以多大概率”。

**5. 代价敏感决策（创新点 3）。** 以 τ* = argmin(C_miss·漏警 + C_false·虚警) 标定阈值，代价比显著改变最优阈值（1:1/5:1 取 0.60，10:1 取 0.20/0.25）；迟滞在各代价比下均降低归一化代价（0.186/0.093/0.256）；三级分级检出率随等级递增（0.209>0.125>0.097）。双源对照验证了创新点 2→3 的可打通性并给出“互补”的定量定位。

**6. 系统实现。** 完成分层解耦的预警系统：在线推理与离线同口径（偏差 7×10⁻⁶ MW）、串口链路端到端验证通过、Streamlit 双模式界面多组合无异常；并搭建 Arduino + 传感器 + LED 的实时采集与分级预警子系统（工程演示，不参与定量评价）。

## 6.2 不足与展望

### 6.2.1 概念漂移

本文观测到明显的概念漂移：测试期上爬坡数量随 Day 推进由 338 衰减至 99，导致测试期主口径事件仅 43 条、各阈值下指标存在波动。本文未对漂移做在线自适应（如滚动重训、增量学习），仅在评价中如实交代。后续可引入基于残差监测的模型更新机制，或采用在线学习缓解分布漂移。

### 6.2.2 概率校准的进一步改进

验证集区间覆盖精准命中 0.80，但测试集覆盖偏宽（0.9009），源于两段误差分布差异。可靠性图显示上爬坡中高概率段存在低估。后续可对 p_up 引入 isotonic 单调校准或分位数回归，进一步提升校准质量与锐度。

### 6.2.3 实时流与真实 NWP

当前实时模式以回放/模拟数据演示，尚未接入真实数值天气预报（NWP）驱动的未来风速注入。真实系统的 2h 预测依赖 NWP，未来可将 NWP 作为特征通道接入，使预警具备真正的“事前”能力；同时可完善串口断连重连、丢帧降级等容错策略的工程化落地。

### 6.2.4 硬件子系统的局限

Arduino 采集子系统受单点传感器与样本量限制，仅验证工程链路，不参与训练与定量评估；传感器标定精度、现场环境干扰、时间同步等仍需在实物联调中进一步检验。

### 6.2.5 消融与对比实验

本文完成了核心链路的对比与决策实验，但未系统开展全套消融（如逐类特征剔除）、TCN 与 LSTM 双模型细粒度对比、自适应阈值（分出力段/时段标定）等实验，可作为后续完善方向。

## 6.3 结语

本文面向风电爬坡预警的实际需求，以“可解释、可复现、可对比”为原则，完成了成因归因、概率化预警、代价敏感决策三个创新点，并落地为可运行、可演示的完整系统。尽管在概念漂移、校准锐度与实时流接入上仍有不足，但所构建的方法体系与系统框架具有良好的可扩展性，可为风电场及调度部门的爬坡预警提供参考。
