# 第三章 数据与事件

本章介绍数据来源、清洗处理、爬坡事件检测与成因归因，回答“数据是什么样、有多少爬坡事件、这些事件由什么引起”三个问题，为第四章建模提供事件清单与责任边界。本章全部数字均为基于脚本的实测结果，可复现。

## 3.1 数据来源

本文采用 SDWPF（Spatial Dynamic Wind Power Forecasting）公开风场数据集（KDD Cup 2022），由 134 台 SL1500/82 型风电机组组成，单机容量 1.5 MW，风场总装机 201 MW，时间跨度 245 天，采样分辨率 10 min，共 4,727,520 条记录（= 134 台 × 245 天 × 144 步），数据结构完整、无丢行。

> 数据说明：该数据来自龙源某风电场（地点未披露），本文仅将其应用场景与考核规则对标蒙西/“三北”基地，不表述为数据来自蒙西。参考原始数据论文 Zhou J. et al., SDWPF: A Dataset for Spatial Dynamic Wind Power Forecasting over a Large Turbine Array, Scientific Data, 2024, 11: 649。

## 3.2 数据清洗

严格按第二章统一口径，数据清洗包含以下步骤，结果汇总于表 3-1。

**表 3-1 数据清洗关键指标**

| 项目 | 实测值 | 处理 |
| --- | --- | --- |
| 记录数 | 4,727,520（134×245×144） | 结构完整，无丢行 |
| 装机容量 | 201 MW | 归一化基准 |
| 平均出力 / 容量系数 | 46.5 MW / 23.1% | 低风速场 |
| Wspd/Patv 同步缺失 | 49,518 条（1.047%） | 按“机组+按天”分段线性插值 |
| 插值后剩余 NaN | 22,320 条 | Day 66/67 整日缺失，不参与特征 |
| Patv 负值 | 1,263,062 条（26.72%） | 置 0 |
| 近零出力（≤1 kW） | 1,385,240 条（29.30%） | 低风速待机，非异常 |

| 角度异常 | 127 条 | 判据 \|Ndir\|>720 或 \|Wdir\|>180，打标记保留 |
| 停机点 | 301,909 个（6.39%） | 判据 Patv≤0 且 Wspd>2.5 |

### 3.2.1 缺失值的两个坑

- **每天 00:00 密集缺测**：49,518 个 NaN 中 5,294 个落在 00:00，约为均匀分布的 15 倍。跨零点的滞后/滚动特征会因此静默变为 NaN。处理办法是按“机组+按天”分段线性插值，并在特征构造时加掩码。
- **Day 66/67 近乎全缺**（19,296 / 11,930 行）：落在训练集内，须在数据说明中交代，并在特征构造时整体跳过这两天。

### 3.2.2 角度异常的条数说明

实测角度异常为 127 条（判据 |Ndir|>720 或 |Wdir|>180）。与早期方案估计的 141 条存在差异，源于开闭区间处理方式不同。本文以代码实测的 127 条为准，并在正文注明判据，不硬抄估计数字。

## 3.3 停机判据与成因分解

停机判据的唯一化已在 2.3.2 详述。据此，对每个爬坡事件用式 (2-2) 做成因分解，并将事件分类为工况型、气象型、混合型。分解残差最大 2.84×10⁻¹⁴ MW，表明该公式对任意 Δt 精确成立，因此归因结果可直接作为事件的客观属性（并非模型推测）。

## 3.4 爬坡事件统计

按第二章口径（Δt=1h，事件合并间隔 ≤ Δt）检测爬坡事件。为兼顾主口径与分级，本文以 10% 为事件检测下限触发事件，按事件内最高幅度标注一/二/三级，并单列 20% 主口径的事件，结果见表 3-2。

**表 3-2 爬坡事件统计（Δt=1h）**

| 指标 | 数值 |
| --- | --- |
| 全量事件（≥10% 检测下限，三档合计） | 1,565 |
| 主口径事件（≥20%） | 752（约 3.07 次/天） |
| 上爬坡 / 下爬坡 | 783 / 782 |
| 气象型 | 1,502（95.97%） |
| 工况型 | 44 |
| 混合型 | 19 |
| 一级 / 二级 / 三级 | 752 / 317 / 496 |

主口径事件约 3.07 次/天，与预期约 3.3 次/天一致。事件量充足，训练与评价不存在正样本不足问题；但同时意味着一级预警“天天有”，必须依靠分级与迟滞机制压住虚警。

### 3.4.1 成因占比与责任边界

气象型事件占 **95.97%**，工况型仅 44 条、混合型 19 条。这印证了 2.3.1 的判断：预警系统主要面对的是气象型爬坡，工况型事件属于“不可避免的漏警”的一部分。因此本文的预警指标**主要在气象型事件上统计**，工况型事件单独列表并对系统降级处理（不承诺预警）。这为模型划清了能力边界，避免把工况型漏警误算为模型缺陷、导致指标失真。

### 3.4.2 事件在测试期的稀疏性（重要数据事实）

按时间划分（Day 1–171 训练 / 172–208 验证 / 209–245 测试），起点落在测试期的主口径事件仅 **43 条**（上行 24 / 下行 19）。这是全场级事件，与机组数无关；其稀疏性来自测试期末端爬坡明显减少——上爬坡数量随 Day 推进由 Day210 段的 338 衰减至 Day230 段的 99。这一时间漂移是第四章泛化评价中不可忽视的背景，也导致测试期各阈值下的事件级指标存在正常波动。

## 3.5 样本构造与数据划分

### 3.5.1 特征工程

构造 14 维风场级聚合特征（表 3-3）。风向采用 sin/cos 编码，避免 0°/360° 断点；所有统计量（均值/标准差）仅用训练集计算，防止信息泄露。

**表 3-3 特征列表（14 维）**

| 序号 | 特征 | 含义 |
| --- | --- | --- |
| 1 | Wspd | 风速 |
| 2–3 | Wdir_sin, Wdir_cos | 风向（sin/cos 编码） |
| 4 | Etmp | 环境温度 |
| 5 | Itmp | 机舱温度 |
| 6–7 | Ndir_sin, Ndir_cos | 机舱方向（sin/cos 编码） |
| 8–10 | Pab1, Pab2, Pab3 | 三叶片角度 |
| 11 | Prtv | 变桨角 |
| 12 | C_mw | 可用装机容量 |
| 13 | P_mw | 当前有功功率 |
| 14 | R | 当前爬坡率 |

### 3.5.2 标签构造

标签来自逐点爬坡标记 `ramp_labels.csv` 的方向字段（−1 下行 / 0 无 / +1 上行）。按“前 N 步历史 → 未来 [t+L, t+L+Δt) 窗内任一触发”的规则生成，其中 L=1h=6 步，Δt=1h=6 步，上爬坡优先。方向作为独立任务分别建模与评价。

### 3.5.3 输入窗与数据划分

- 输入窗 N = 72 步（12 h 历史），步长 10 min。
- 数据严格按时间切分：训练 Day 1–171 / 验证 Day 172–208 / 测试 Day 209–245，**禁止 shuffle**，以模拟真实的前向预测场景。
- 滑窗采样结果：训练 24,327 / 验证 5,328 / 测试 5,316 个样本（X 形状 (N, 72, 14)）。

### 3.5.4 边界处理

t_idx=0 无“前一时刻”，前向差分不可信，故置 R=NaN 并同步清除方向与等级标记，与序列末尾 6 行的 NaN 保持首尾对称，避免无效边界样本进入训练。

## 3.6 本章小结

本章基于 SDWPF 实测数据完成清洗与事件检测：全量事件 1,565 条、主口径 752 条（约 3.07 次/天），其中气象型占 95.97%。成因分解公式精确成立（残差 2.84×10⁻¹⁴ MW），据此为预警划定了“主要面对气象型、对工况型降级”的责任边界。同时交代了测试期仅 43 条主口径事件这一重要数据事实。样本按时间严格划分、无 shuffle，构造 14 维特征与 72 步输入窗，为第四章建模奠定基础。
